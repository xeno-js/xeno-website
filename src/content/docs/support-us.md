## Support Xeno.JS

Xeno.JS is an open-source project built for developers who want explicit application architecture for TypeScript.

If you find Xeno.JS useful, there are several simple ways to support the project and help it reach more developers.

You don't need to write code or become a contributor.

---

## 💚 Become a Sponsor

If you believe in the long-term vision of Xeno.JS, consider becoming a sponsor.

Sponsorship provides ongoing financial support that helps make time available for the continued development and maintenance of the project.

Your sponsorship helps support work across:

* core framework development;

* ecosystem packages;

* documentation;

* examples;

* CLI and developer tooling;

* maintenance and releases;

* infrastructure and project operations.

## Become a Sponsor

[Sponsor Xeno.JS on GitHub](https://www.github.com/xeno-js/)

Whether you sponsor the project as an individual or as a company, your support helps Xeno.JS continue to grow as an open-source framework.

If Xeno.JS is part of your team's technology stack, sponsorship is also a direct way to support the continued development of the project you depend on.

---

## ☕ Buy Me a Coffee

If Xeno.JS has helped you, you can support the project directly by buying the maintainer a coffee.

Your support helps make time available for the continued development of:

* Xeno.JS core packages;
* documentation;
* examples;
* tooling;
* maintenance;
* the wider ecosystem.

**[Buy Me a Coffee](https://www.buymeacoffee.com/xenojs)**

Every contribution is appreciated.

---

## ⭐ Star Xeno.JS on GitHub

A GitHub star is one of the easiest ways to support an open-source project.

It takes a few seconds, costs nothing, and shows that there is interest in Xeno.JS.

It can also help the repositories become more visible to developers exploring TypeScript frameworks and application architecture.

### Xeno.JS

⭐ [Star `xeno-js`](https://github.com/xeno-js/xeno-js)

The main Xeno.JS application architecture framework.

### Xeno Shared

⭐ [Star `xeno-shared`](https://github.com/xeno-js/xeno-shared)

Shared domain primitives and application contracts.

### Xeno Vue

⭐ [Star `xeno-fe`](https://github.com/xeno-js/xeno-fe)

The Vue implementation of the Xeno.JS application architecture model.

### Xeno CLI

⭐ [Star `xeno-cli`](https://github.com/xeno-js/xeno-cli)

The official Xeno.JS CLI and scaffolding tools.

## 📣 Spread the Word

One of the most valuable things you can do is simply tell other developers about Xeno.JS.

You can:

* share Xeno.JS with your team;
* recommend it to another TypeScript developer;
* share the website or documentation;
* mention it in a TypeScript community;
* share a project built with Xeno.JS;
* write about your experience using the framework;
* post about Xeno.JS on social media;
* include Xeno.JS in discussions about TypeScript architecture.

You don't need to be a maintainer or contributor to help the project grow.

If you have used Xeno.JS, **your real experience is more valuable than promotion for its own sake.**

---

## 🧪 Try Xeno.JS

Another way to support the project is to give it a try.

Use Xeno.JS for a:

* personal project;
* prototype;
* proof of concept;
* internal application;
* side project.

If you find it useful, tell other developers.

If you don't, your experience can still help others understand where Xeno.JS fits and where it doesn't.

---

## ❤️ Thank You

Open-source projects grow through people who choose to use them, talk about them, and support them.

Whether you buy a coffee, star a repository, share Xeno.JS with a colleague, or simply give the framework a try, it helps.

**Thank you for supporting Xeno.JS.**
